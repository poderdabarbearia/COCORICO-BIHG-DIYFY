# WhatsApp Campaign Engine
Audience snapshot→jobs→claim→pre-send→provider→delivery→reply. Use idempotência, pacing, quiet hours, pause/resume, target tipado; sem retry cego de envio incerto. Grupos opt-in; replies entram no mesmo scheduling engine.
